# Registro de decisiones y desviaciones

Fecha: 31 de octubre de 2026. La solicitud de demo posterior autoriza implementación y publicación de una **demo independiente**, no la web definitiva.

| Aspecto | Especificación v1.0 | Demo y justificación |
| --- | --- | --- |
| Alojamiento | Cloudflare Pages propuesto para la futura web | GitHub Pages por instrucción expresa del usuario. Repositorio público personal `mmlab-dev/jaime-valiente-web-demo`, sin organización ni dominio personalizado. |
| Aprobación | No iniciar implementación antes de aprobación expresa | La solicitud posterior encarga desarrollar, probar y publicar esta demo. No equivale a aprobación de una web definitiva. |
| URLs | Rutas del dominio propio y redirecciones de migración | Subdirectorio real `/jaime-valiente-web-demo/`. No se ejecuta una migración ni redirecciones en la web existente. |
| Índice legado | Conservar `/servicios-profesionales` durante la migración | No se añade a la demo porque no hay migración y la solicitud limita las páginas comerciales. Inicio reúne los tres accesos de servicio. La futura migración mantiene pendiente el mapa original. |
| Clientes | Entrada provisional al canal existente después de verificarlo | Pantalla explícitamente demostrativa. Sin enlace al Apps Script, SaaS, autenticación ni carga de archivos, conforme a la solicitud posterior. |
| Legales | Textos finales aprobados antes de publicar una web definitiva | Tres pantallas demostrativas con límites y datos pendientes; no se presentan como textos jurídicos definitivos. |
| Datos del profesional | Publicar solo información acreditada | Se mantiene la marca confirmada. El despacho muestra una lista de datos pendientes en lugar de biografía, colegiación o fotografía inventadas. |
| SEO | Preparar indexación y SEO local de la futura web | Títulos y descripciones propios, canónicas del dominio de demo y `noindex, follow`. Sin sitemap promocional, perfiles locales, schema profesional o cambios de indexación del dominio real. |
| Bronce | `#8B6B45`, sujeto a contraste | Se mantiene en detalles. Para números y texto pequeño se usa la variante `#75583A`, tras detectar ratios de 4,21–4,42 con el tono original. |
| Composición | Wireframes estructurales | Desarrollo editorial propio con panel tipográfico y adaptación específica de tableta. No se modifican las siete páginas ni la cobertura de servicios. |
| Fotografía | Real y autorizada o versión tipográfica | Versión tipográfica, sin atribuir un retrato, equipo o instalaciones ficticios. |

Se conserva la separación entre Civil, Laboral y Reclamaciones: Civil mantiene responsabilidad e indemnizaciones; Laboral sigue dirigido a empresas y autónomos; Reclamaciones reúne deudas, negociación, monitorios y ejecución sin repetir el contenido de las otras áreas.
